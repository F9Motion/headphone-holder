# Features
* Minimalistic design
* Wireless
* With RGB diodes
* Custom
# How it works
Raspberry pi pico do all work. It put to diodes signals and control them. MCP83731 is for battery and charge the battery.
# How to assemble
1. Print PCB from **JLCPCB**
2. Print **CAD** files
3. Order microcontrollers from **BOM** and solder it to PCB
4. Flash
# How to Flash
1. Install arduino IDE
2. Download firmware
3. Connect your PC to Raspberry pi pico
4. Upload firmware
